We’re building a lightweight, modded minecraft server wiki website, with guided tutorial for players to join our server namely "Basement Dwellers", a bluemap mod integration to our website, FAQ, and other stuff, among them is table of contents, tabs, about us, etc.

The setup guide is on ~/Project/BasementDwellWeb/install-guide-mods.txt for players to follow

The web should let a user enter a rough web idea, then generate an editable project brief with:

- web summary
- target users
- core features
- recommended tech stack
- pages/routes
- possible data model
- build phases
- risks/edge cases
- final copyable starter prompt for a coding agent

Keep the scope small: no auth, no database, no payments. We'll focus more on Astro-like development, meaning static webpages with beautful premium looking theme, with near-zero js. Instant performance/loading times, etc. Use Tailwind, shadcn-like ui, or any stack for this minimal development. For now, plan the architecture, components, routes, data flow, and implementation steps.

Check the installed skills if its appropriate, and find skills for developing the project.
